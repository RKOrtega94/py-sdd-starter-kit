# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records (ADRs) for this repository. ADRs document significant design decisions and their context/consequences.

## How to Use ADRs

### Creating a New ADR

1. Create a new file in `docs/decisions/` named `ADR NNN: <title>.md` where NNN is a sequential number.
2. Use the ADR template from `docs/templates/` if available.
3. Include: Status, Context, Decision, Consequences.
4. After creation, tag the decision in relevant `SPEC.md` or `PLAN.md` files.

### ADR Status Values

- **Proposed**: Decision under consideration, not yet adopted.
- **Accepted**: Decision adopted, team agrees to follow it.
- **Superseded**: Decision replaced by a newer one; keep for historical reference.
- **Deprecated**: Decision no longer recommended but still in effect for now.

### Referencing ADRs

- Reference ADRs in `SPEC.md` using: `See ADR 001`.
- Reference ADRs in `PLAN.md` when mapping architectural impact.
- Keep ADRs updated when circumstances change.
